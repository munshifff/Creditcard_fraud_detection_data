This project contains my Phase 02 credit-card fraud detection implementation based on Kennedy et al. (2024). It trains baseline models and compares their results with the paper. Install the packages with pip install -r requirements.txt, open Phase 2.ipynb in Jupyter, and run the cells in order. Keep creditcard.csv in the same folder as the notebook. The notebook includes saved results and discusses the differences and limitations of the comparison. Dataset source: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud .
